# fledge

fledge exists so that the boring middle of software work — start it, run it, check it, review it, ship it — is the same small set of commands in every repository you touch, whatever language is inside. It should be useful the second you `cd` into an existing project, with nothing configured and nothing to learn, and it should get more useful, not more brittle, as you write your project's habits down. Anything that assumes one ecosystem belongs outside the core, so the tool you install stays small and the parts you opt into are yours to choose. Every guardrail it has — the refused push, the shown-before-run setup command, the untrusted plugin — is there because the alternative is discovering the problem after the damage. And because half the people using it now are agents, everything a person can read, a machine can parse.
